# Estrategia de tienda Shopify — Dropshipping (España)

Plan completo, de menor a mayor presupuesto posible, para lanzar una tienda Shopify con máximas probabilidades de éxito en el mercado español.

**Producto elegido: cepillo autolimpiante para mascotas** (ver justificación completa en `docs/01`).

## Principio rector de todo el plan

**Gratis primero, pago solo si está justificado y confirmado por ti.** En cada documento se indica explícitamente:
- Qué alternativa gratuita existe para cada herramienta/app.
- Cuándo (si acaso) merecería la pena pagar, y por qué.
- Qué acciones tienen coste real o pueden afectar a la tienda — esas **requieren tu confirmación explícita antes de ejecutarse** (contratar el plan Shopify, comprar dominio, dar de alta cualquier suscripción, lanzar publicidad de pago, alta como autónomo/gestoría).
